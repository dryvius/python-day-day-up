## 模块目标

能用 Python 写正常程序，而不是只会零散脚本。

一切后续后端、异步、Agent 开发的语言底座。

## 建议学习方式

1. 按章节顺序阅读文档（每章保留知识地图骨架；知识点讲解按「先直觉再纠错」推进）
2. 只把「必掌握」吃透，其余按兴趣加餐
3. 立即做对应 `exercises/` 练习，先按自己的理解写出来再对照
4. 用模块末尾的自检确认是否可进入下一模块

## 模块通关门禁

- [ ] 所有章节基础练习达到各自“通过线”
- [ ] 能在 45 分钟内完成一个读 JSON、按条件统计并输出结果的小程序
- [ ] 程序至少拆成 3 个职责明确的函数，不修改入参容器，不依赖全局可变状态
- [ ] 能把程序拆成两个模块，并用 `python -m` 或明确入口运行
- [ ] 能解释函数、模块、异常输入分别会如何影响后续 Agent 工具代码
